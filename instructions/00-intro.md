# Introduction

This lab takes a field-services app from a starter template to a deployed, data-driven application using Rayfin, Microsoft Fabric, and the GitHub Copilot app. Rayfin provides managed backend capabilities so you can focus on the application instead of wiring each cloud service yourself.

The scenario centers on Contoso DIY, a home-improvement retailer expanding into home services. Managers create work orders and assign jobs to service professionals. Service pros create profiles, accept and complete jobs, and the business uses operational data to understand how the service is performing.

During the lab, you will:

- Bootstrap a field-services app and inspect its Rayfin configuration and data model.
- Provision a managed backend in Microsoft Fabric, run the app locally, and verify its hosted deployment.
- Use the GitHub Copilot app to add a schema-backed comments feature.
- Seed the app with sample operational data and build a Fabric semantic model over it.
- Use Rayfin's Semantic Model connector to bring insights back into a dashboard in the app.

Complete the exercises in order. Each exercise builds on the app, data model, deployment, or Fabric resources created in the previous exercises.
