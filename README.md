# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥LAB690: Ship AI apps fast with Rayfin, a managed backend as a service
### Session description

Skip the infrastructure plumbing and ship a real enterprise app. In this hands-on lab, you will build a work-order management app for Contoso DIY with Rayfin, a managed backend as a service. Start from a template, deploy to Microsoft Fabric, add a feature with GitHub Copilot CLI, and bring operational insights back into the app with Rayfin's Semantic Model connector.

### 🚀 Getting started

#### In a guided session

If you're following along during a live session:

1. Open the lab environment provided for the session and sign in to GitHub and Microsoft Fabric.
2. Open [`instructions/`](instructions/README.md) and start with the environment setup.

#### On your own

If you're learning at your own pace:

1. Clone this repository.
2. Install Node.js, npm, Visual Studio Code, and GitHub Copilot CLI, then sign in to GitHub and Microsoft Fabric.
3. Follow the lab steps in [`instructions/`](instructions/README.md). Deploying the app requires a Fabric workspace and may incur cloud costs.

### 🎯 Learning outcomes

By the end of this session, you will be able to:

- Bootstrap and deploy a full-stack field-services app using Rayfin and Microsoft Fabric.
- Use GitHub Copilot CLI to evolve an app's schema and user interface with a managed backend.
- Connect a Microsoft Fabric semantic model to an in-app dashboard using Rayfin's Semantic Model connector.

### 💻 Technologies used

- Rayfin (including the Semantic Model connector)
- GitHub Copilot CLI
- Microsoft Fabric (SQL Database and semantic models)
- Visual Studio Code
- TypeScript
